# NoteApp

Пример Android-приложения для создания заметок. Основные возможности:

* Создание и редактирование текстовых заметок.
* Рисование поверх заметки линий разного цвета.
* Масштабирование жестами.
* Хранение заметок в памяти приложения.
* Просмотр списка заметок, отсортированного по дате.

Проект построен на Jetpack Compose. Файлы Gradle и код размещены в каталоге `app/`.

Это базовый каркас, предназначенный для дальнейшего развития (экспорт в PDF, группировка заметок и другие функции).
